# CSE423 – 3D Ghost Horror Game

## Project Description
This is a 3D horror game developed using Python and PyOpenGL for the CSE423 Computer Graphics course.

## Features
- 3D Player Movement
- Multiple Camera Modes (First, Third, Top View)
- Enemy AI (Ghosts)
- Health & Fear System
- Shooting Mechanism
- Level System
- Powerups

## Controls
Arrow Keys - Move Player  
K - Shoot  
C - Cheat Shoot  
D - Change Camera  
R - Restart Game  

## Technologies Used
- Python
- PyOpenGL
- GLUT
- GLU
